MNIST Digit Classification — Inference Visualizer

An interactive visualization of a neural network

This app shows a compact multi-layer perceptron (MLP) trained on MNIST. Draw a digit and watch the activations propagate in real time through every fully-connected layer.

How it works:

  • Draw: click and drag on the 2D grid (top left) to sketch a digit
  • Watch: follow your sketch as it flows through the network's layers in 3D space
  • Predict: check the probability for each digit (0–9) in the chart (top right)

Network architecture (default export):

  • Input layer: 28×28 pixel grid (your drawing)
  • Dense layer 1: 784 → 128 neurons with ReLU
  • Dense layer 2: 128 → 64 neurons with ReLU
  • Output layer: 64 → 10 logits → softmax probabilities

3D controls:

  • Rotate: hold the left mouse button and drag
  • Pan: hold the right mouse button and drag
  • Zoom: use the scroll wheel

Color coding:

  • Nodes: color shows activation strength (dark blue for low/negative values, warm coral for strong positive activations)
  • Connections: warm colors mark strong positive contributions, cool tones negative influence, and dim lines near-zero weight.

Training timeline:

  • The slider at the bottom scrubs through 35 checkpoints of a real training run, from random initial weights to 50× the dataset size, so you can watch the network learn.

Real-time features:

  • Layer activations: instanced spheres show each neuron's activation, color-coded by strength.
  • Key connections: each target neuron highlights its strongest incoming weights for readability.
  • Live probabilities: the bar chart updates logits → softmax values in real time.

The network is deliberately small so the 3D view stays smooth and responsive.
