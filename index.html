Interactive, browser-based demos for an intro Computer Science & Cybersecurity course — built to be explored, not just read.

01 · Encoding

Text Encoding Explorer

Watch text become bits. Three linked views — ASCII, Unicode/UTF-8, and Huffman coding — with synchronized hover-highlighting across the text, binary, hex, and a live-built compression tree.

02 · Neural Networks

Neural Network Visualizer

A 3D, real-time view of a small neural network classifying handwritten digits (MNIST). Draw a digit and watch activations propagate neuron-by-neuron, then scrub a training timeline from random weights to a fully trained model.

Open demo →
03 · Embeddings

Word Embeddings Explorer

Search a word and see the real 100-dimensional GloVe vector behind it, then see which dimensions are most unusual for that word and which other words sit at each dimension's extremes — a concrete warm-up for Attention.

Open demo →

About this series

Every demo is a dependency-free static page (HTML/CSS/JS, no build step) sharing one visual language — "Blueprint": a dark, technical-drawing aesthetic with cyan structure lines and a warm "redline" orange reserved for hover and highlight states. That consistency is deliberate: once a student learns to read one demo, they can read all of them.
